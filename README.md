# -NJOL-Launcher
NapoleoJavaON — неофициальный форк Zalith для Android. Фокус на оптимизацию и помощь новичкам: встроенный анализатор крашей, безопасный справочник по рендерам, префлайт-диагностика и гайды по созданию модов прямо с телефона.

**NapoleoJavaON (NJOL)** — это неофициальный, расширенный форк лаунчера **Zalith Launcher 2+** (который, в свою очередь, основан на Zalith Launcher 2 и PojavLauncher). 

Наша главная цель — сделать запуск Minecraft: Java Edition на Android не только возможным, но и максимально понятным, безопасным и удобным для обычного пользователя. Мы убрали «магию» и добавили прозрачность: теперь лаунчер сам подскажет, почему игра вылетела, как настроить рендер и даже поможет создать свой первый мод.

> ⚠️ **Важно:** Это **неофициальная модификация**. Проект никак не связан с командами Zalith Launcher, PojavLauncher, Mojang Studios или Microsoft.

## 🌟 Текущие возможности (Что уже работает)

* 🛡️ **NJOL Crash Insight (Анализатор крашей)**: Встроенная система диагностики. Вместо непонятных логов лаунчер сам анализирует `crash-report` и папку `mods`, выявляя наиболее вероятную причину сбоя (конфликт модов, нехватка ОЗУ, ошибка рендера). Пользователь получает понятную инструкцию по исправлению.
* 📖 **Справочный центр (Help Center)**: Полноценная встроенная база знаний. Подробные гайды по настройке рендеров (MobileGlues, Krypton, Zink), Java, памяти, загрузчиков модов и безопасности аккаунтов.
* 🔗 **Безопасные ссылки**: В справочнике собраны только официальные ссылки (GitHub, F-Droid) на Termux, драйверы, MobileGlues и другие инструменты. Никаких сторонних сайтов с вирусами.
* ⚙️ **NJOL Preflight (Предзапускная проверка)**: Экран диагностики перед запуском игры. Показывает версию Android, лимиты ОЗУ и предупреждает о потенциальных проблемах до старта Minecraft.
* 🧑‍💻 **NJOL Creator Lab**: Пошаговый гид для новичков по созданию собственных модов на Fabric. Объясняет, как настроить окружение через Termux (на телефоне) или GitHub Codespaces (в облаке), и как безопасно использовать ИИ в разработке.
* 🎨 **Современный UI/UX**: Полностью переработанный интерфейс на Jetpack Compose (Material 3 Expressive). Кастомные баннеры, градиенты, адаптивная навигация, удобная статистика времени игры и чтение Changelog прямо в лаунчере.
* 🔄 **Экосистема**: Настройка масштабирования разрешения (по умолчанию 65% для плавности), поддержка темной темы, Onboarding для новых пользователей.

## 🚀 В разработке (Ближайшие патчи)

Проект активно развивается. В следующих обновлениях запланировано:
* 🖼️ **Кастомный экран загрузки**: Фирменная анимация с логотипом NJOL во время запуска игры.
* 📚 **Расширение Creator Lab**: Новые подробные туториалы по созданию модов, работе с API и сборке JAR-файлов.
* ⚡ **Оптимизация**: Работа над снижением фризов при компиляции и загрузке чанков, оптимизация потребления ОЗУ и улучшение стабильности на слабых устройствах.
* 🛠️ **Улучшение кастомного меню**: Еще больше настроек для сохранения конфигураций, управления и аккаунтов.
* 📖 **Расширение справочника**: Добавление новых руководств и подробных описаний для всех аспектов лаунчера.

## 🧠 О разработке и использовании ИИ

Мы считаем важным быть абсолютно прозрачными с нашим сообществом. В современном мире разработки инструменты на базе искусственного интеллекта — это мощный ускоритель, но **не замена разработчику**.

* **Визуальные улучшения**: ИИ используется исключительно как продвинутый инструмент для генерации и адаптации сложного визуального кода (анимации Jetpack Compose, градиенты, верстка карточек и баннеров).
* **Текстовый контент**: ИИ помогает структурировать и оформлять большие объемы текста для Справочного центра и документации, чтобы информация легко читалась.
* **Ручная работа**: Вся архитектура проекта, логика работы (включая алгоритмы анализатора крашей), интеграция с рендерерами, UX-дизайн и финальная сборка выполняются исключительно человеком. Любой сгенерированный код тщательно проверяется и тестируется перед добавлением в релиз.

## 🛠️ Сборка из исходников (Building from Source)

Для сборки проекта вам понадобится **Android Studio** (последняя версия) и **JDK 17**.
1. Склонируйте репозиторий или скачайте ZIP-архив с исходным кодом из раздела Releases.
2. Откройте проект в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Соберите проект (`Build -> Make Project`) или запустите на устройстве.
