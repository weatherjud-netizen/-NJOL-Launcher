# NapoleJavaON Launcher (NJOL)

**NJOL 1.0** — неофициальный изменённый Android-лаунчер для Minecraft: Java Edition с чёрно-белым фирменным интерфейсом, офлайн-профилями, менеджером версий и загрузчиков, справочным центром, безопасным анализатором крашей, галереей фонов и настраиваемой игровой шестерёнкой.

> **Это изменённая версия.** NJOL не является официальным продуктом Mojang, Microsoft, Zalith Launcher или PojavLauncher и не поддерживается этими проектами.

## Возможности

- фирменная оболочка NapoleJavaON Launcher / NJOL;
- офлайн-аккаунты и сохранённые локальные профили;
- поддержка загрузчиков и компонентов, присутствующих в исходном проекте, включая Forge, Fabric, NeoForge, Quilt, Legacy Fabric, OptiFine и Cleanroom;
- справочный центр по Java, рендерерам, плагинам, аккаунтам, логам и лицензиям;
- локальный безопасный анализ краш-логов без автоматического удаления модов;
- фоновые изображения и импорт собственных изображений/видео через системный выбор файлов;
- изменение размера, позиции и прилипания игровой шестерёнки;
- Debug-сборка через GitHub Actions.

```bash
./gradlew --no-daemon :ZalithLauncher:testDebugUnitTest
./gradlew --no-daemon :ZalithLauncher:assembleDebug -Darch=all
```

Требуются JDK 17 и Android SDK, указанные в [RELEASE_RU.md](RELEASE_RU.md). Для Microsoft OAuth и CurseForge нужны собственные настройки; в публичный репозиторий нельзя добавлять секреты.

## Происхождение и атрибуция

NJOL основан на GPLv3-коде [Star1xr/ZalithLauncher2Plus](https://github.com/Star1xr/ZalithLauncher2Plus), который, в свою очередь, использует работу [ZalithLauncher/ZalithLauncher2](https://github.com/ZalithLauncher/ZalithLauncher2) и компоненты [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher/tree/v3_openjdk/app_pojavlauncher/src/main/jni). Авторские notices, заголовки исходных файлов, тексты лицензий, имена авторов и ссылки на upstream сохранены там, где этого требуют лицензии или корректная атрибуция.

Изменения NJOL должны распространяться под GPLv3 вместе с соответствующим исходным кодом. Перед публикацией APK необходимо отдельно проверить полноту исходников встроенных JRE/JAR/AAR/SO и уведомлений сторонних компонентов. Подробности — в юридических документах проекта.

## Ограничения текущего APK

Готовые APK являются Debug-сборками, подписанными публичным тестовым ключом исходной конфигурации. Для настоящего публичного релиза нужен новый закрытый release keystore и проверка на реальном Android-устройстве. Microsoft-вход, онлайн-загрузка и запуск конкретных сборок Minecraft зависят от настроек, сети, устройства и состава ресурсов.
