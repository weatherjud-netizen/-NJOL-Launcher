# 🚀 NapoleoJavaON Launcher (NJOL)

### An independent Minecraft: Java Edition launcher for Android

**Не просто запустить Minecraft. Понять, настроить и играть.**

NapoleoJavaON Launcher (NJOL) — независимый неофициальный модифицированный форк открытого лаунчера Zalith Launcher 2+, развитие которого направлено на создание более понятной, удобной, информативной и персонализируемой среды для запуска Minecraft: Java Edition на устройствах Android.

Проект основан на существующих открытых разработках и включает собственные изменения, дополнительные инструменты, переработанные пользовательские интерфейсы, справочные материалы и новые функциональные решения.

Главная задача NJOL — не просто предоставить пользователю возможность запустить игру, а помочь ему разобраться в особенностях Minecraft Java Edition на Android.

Мы хотим сделать технически сложные процессы более доступными для начинающих пользователей, одновременно сохранив гибкость и возможности настройки для опытных игроков.

# 📖 1. О проекте

NapoleoJavaON Launcher — самостоятельный проект по развитию и модификации лаунчера Minecraft: Java Edition для Android.

В основе NJOL лежат открытые разработки Zalith Launcher 2+, который, в свою очередь, связан с развитием Zalith Launcher 2 и PojavLauncher.

NJOL не является официальной версией указанных проектов, не представляет их разработчиков и не заявляет о наличии официального сотрудничества с ними.

Основное направление развития NJOL — улучшение пользовательского опыта, расширение информационных возможностей лаунчера и создание дополнительных инструментов, помогающих пользователям самостоятельно настраивать Minecraft Java Edition.

Проект развивается независимо и имеет собственное название, оформление, документацию, функциональные дополнения и планы дальнейшего развития.

# 🎯 2. Цели и философия проекта

Мы считаем, что запуск Minecraft Java Edition на Android не должен требовать от пользователя предварительного изучения большого количества технической документации.

На практике начинающие игроки сталкиваются с различными трудностями:

- Непонимание различий между графическими рендерами.
- Сложности с выбором и настройкой Java.
- Неправильное распределение оперативной памяти.
- Проблемы совместимости модификаций.
- Ошибки при установке загрузчиков модов.
- Непонимание причин игровых вылетов.
- Сложности с поиском проверенных источников загрузки.
- Недостаток понятных инструкций непосредственно в лаунчере.

NJOL стремится постепенно решать эти проблемы.

Основной принцип проекта:

**Не просто предоставить настройку, а объяснить пользователю, для чего она нужна, как работает и к каким последствиям может привести её изменение.**

Мы не стремимся полностью ограничивать пользователя автоматическими решениями. Напротив, наша задача — предоставить ему необходимую информацию для самостоятельного выбора.

## ⚙️ NJOL Preflight

NJOL Preflight — система предварительной диагностики перед запуском Minecraft.

Её задача — предоставить пользователю полезную информацию об устройстве и предупредить о потенциальных проблемах до начала игровой сессии.

В зависимости от доступных системных данных диагностика может включать:

- Информацию об Android.
- Сведения о доступной оперативной памяти.
- Проверку некоторых параметров конфигурации.
- Предупреждения о возможных ограничениях.
- Информацию, полезную для подготовки игрового окружения.

Preflight не является полноценной системой аппаратного тестирования и не может гарантировать отсутствие ошибок при запуске.

# 📱 5. Поддержка устройств

NJOL разрабатывается для Android-устройств, способных запускать поддерживаемые конфигурации Minecraft Java Edition.

В проекте уделяется внимание совместимости с различными аппаратными платформами.

В частности, рассматриваются:

- ARM64 (AArch64).
- Устройства с различными графическими процессорами.
- Различные версии Android.
- Различные конфигурации оперативной памяти.

Для распространения приложения предусматриваются соответствующие варианты APK, включая универсальную сборку, если её состав и используемые компоненты обеспечивают необходимую совместимость.

Наличие универсального APK не означает гарантированную работу на абсолютно каждом Android-устройстве.

Совместимость зависит от ABI, версии Android, системных библиотек, драйверов и других технических требований.
